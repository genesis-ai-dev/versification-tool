# Review Endpoint Security

**Acceptance Criteria:**

1. Ensure the current API endpoints are as secure as they can be with the current auth scheme (basic)  
2. Ensure that future endpoints will automatically include this same level of security, unless developers take steps to avoid this  
3. Review the current AWS deployment scheme and best practices, then document recommendations for Frontier R\&D’s own eventual deployments to ensure reasonable protections against:  
   1. Unauthorized use  
   2. DDOS attacks
